Contributing

- Fork or copy the project.
- Follow these steps locally:

1. Install dependencies:

```bash
python -m pip install -r requirements.txt
```

2. Use VS Code to make changes. Recommended tasks are available in `.vscode/tasks.json`.
3. Run unit tests (none included by default) or do a dry-run:

```bash
python agent.py --dry-run --simulate -c config.yaml
```

4. When ready, package and share.
